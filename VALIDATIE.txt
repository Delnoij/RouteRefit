RouteRefit 0.5.15 Beta - validation report, 2 November 2026

Scope
The first public beta packages the existing route editor with a per-user Windows
installer, English publication documents and six portrait manuals. Copyright is
attributed to Marco Delnoij; the GitHub account is Delnoij. These publication changes
do not replace the route-alignment algorithm.

Recorded baseline
392 unit tests passed locally. GitHub run 41483317769 also passed all 392 tests
(5.248 seconds), eight interface checks in six languages, the Windows build,
packaging and installer tests at revision 626e208945e62729c92ae10fdd5c5212b417d40a.
https://github.com/Delnoij/RouteRefit/actions/runs/41483317769
Subsequent publication/copyright edits require a fresh hosted run. The exact
revision and run for each downloadable build are in BUILD-INFO.json and
INSTALLER-INFO.json; consult the release's linked successful run.

Interface checks cover import, statistics, segment connections, via points,
access review, separate activity/timing settings, proposal cancellation and
acceptance, undo, manual editing during stalled downloads, stale responses,
offline road indexing, visible progress, stopping and retained original files.
Only synthetic test data is used in automated checks; no real account uploads.

Installer checks
Inno Setup 7.1.1 is pinned by SHA-256 and checked for a valid Pyrsys B.V. signature.
Tests cover first install, refusal while the program file is locked, reinstallation,
byte-for-byte preservation of synthetic routes/edits/maps/preferences, uninstall,
removal of this installation's task and retention of another copy's task.
The user's existing installations are not used as installer test targets.

Documentation and privacy checks
Six manuals contain 47 portrait A4 pages and 33 chapters each. All pages are
rendered and checked for text bounds; changed pages are visually reviewed.
Only approved synthetic examples and screenshots are included. Source and Windows
archives are checked against the reviewed data manifest. Source hashes must match
the exact build input. These checks are not a general-purpose secret scanner.
Personal routes, edits, maps and settings are excluded from public downloads.

Outstanding
Testing on a separate Windows 11 PC without Python, broader real-device
navigation tests, and actual service imports remain outstanding. Windows 11 is
the target platform; the hosted build runner uses Windows Server 2025 and does
not substitute for a separate real Windows 11 user test. No SignPath acceptance,
certificate, signed release or independent reviewer is claimed.
