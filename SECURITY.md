# Security and sensitive data

Do not publish signing keys, tokens, identity documents or personal route data in issues. For a suspected vulnerability, use GitHub's private vulnerability reporting if Delnoij has enabled it in this repository. The setting is not enabled by this file. If no private channel is available, first ask the maintainer for one without posting exploit details or sensitive files. There is no support-response-time guarantee. Fixes are initially maintained in the current beta branch.
