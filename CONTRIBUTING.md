# Contributing

Application contributions use GPL-3.0-only. Keep third-party copyright and licence notices. Submit external changes through pull requests, describe their effect and include a regression test for a reproduced bug. Run the unit tests and UI smoke checks. Test without contacting map services in automated tests. Do not include personal routes, photographs, signing keys or tokens. Route-file fixtures must be synthetic or explicitly cleared for public redistribution. Every release requires the maintainer's review; signing and publication require a separate explicit approval.
